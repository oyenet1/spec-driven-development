## Step-by-Step Execution Workflow for Any Campaign

When asked to create marketing assets, follow this sequential 6-step protocol:

```
[1. Profile Dream Avatar & Pain]
   ↳ [2. Engineer Grand Slam Offer & HVCO Bait]
      ↳ [3. Draft Direct-Response Ads (Power 4 & Story)]
         ↳ [4. Construct Landing Page / Sales Page (17 Steps)]
            ↳ [5. Deploy Email Cadence & Magic Lantern]
               ↳ [6. Build Sales Closing / WhatsApp Conversation Flow]
```

### Step 1: Avatar & Core Pain Identification
- Define the dream buyer's 2:00 AM nightmare, biggest frustration, preferred communication channel, and skepticism triggers.

### Step 2: Grand Slam Godfather Offer Architecture
- Calculate and maximize the Value Equation.
- Add 3 sweetener bonuses that solve subsequent problems.
- Attach an ironclad guarantee and justify scarcity/urgency.

### Step 3: Direct-Response Ad Creation
- Apply the Power 4 Meta Ad Framework: Hook, Lead, Story/Agitation/Mechanism, Call to Action.
- Provide variations: Short punchy copy, medium value copy, and long story ad.

### Step 4: High-Converting Landing Page Construction
- Follow the 17-Step Secret Selling System wireframe.
- Ensure mobile-first speed, sticky CTA buttons, and proof stacking.

### Step 5: Email Automation & Nurture Deployment
- Set broadcast schedule (Tuesday 10:00 AM, Thursday 2:00 PM, Sunday 8:30 PM).
- Deploy the 4-Phase Email Machine with plain-text formatting and slippery-slope copywriting.

### Step 6: Closing & Conversational Sales
- For Global B2B/High-Ticket: Deploy the 2-step Triage (15 min) + Strategy Session (45 min) doctor-style closing script.
- For Nigeria / Direct-to-Consumer: Deploy the 4-part WhatsApp status sequence and 1-on-1 DM closing scripts.
